# Week 1 Lab: Student Introduction Card

## Task

Create `lab01_student_card.py`. Ask for a name, student ID, department, GitHub username and one programming goal. Print a clear card using f-strings.

## Acceptance Checks

1. All five pieces of input appear in the card.
2. The output is readable and has a heading.
3. Change one answer and verify that the output changes.
4. Explain what `input()` stores and what `print()` displays.

## Stretch Task

Try an empty name. What does the current program do? Write one sentence about a future improvement.

## GitHub Submission

1. Create `week01/lab-quiz/` in your own course repository and save `lab01_student_card.py` there. Keep weekly homework in `week01/` outside this folder.
2. Add a short README note with one test you ran and one thing you changed after testing.
3. Commit with a specific message, such as `week01: complete student introduction card`.
4. Show the running program and your commit history to the instructor.

## Assessment (10 Points)

- Working behavior and required rules: 5
- Meaningful tests, including a boundary or error case: 2
- Readable names and clear output: 2
- GitHub commit and README note: 1
